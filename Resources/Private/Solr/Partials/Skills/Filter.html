One filter (facet) as a disclosure: a button-like summary with the count of active options, a panel of options that toggle. A selected option links to the URL that removes it, an unselected one to the URL that adds it (operator OR: more options widen the list). Plain links, so it works without JavaScript; the skills search script loads them in place. The typo3.org look lists the filters open in its sidebar.
