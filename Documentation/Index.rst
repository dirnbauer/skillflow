Skillflow
=========

----

Skillflow runs nr_llm-managed skills in TYPO3 page and workspace review
workflows. nr_llm owns skill sources, imports, activation and lifecycle state;
Skillflow stores the assignments to pages, backend users and workspace stages,
executes skills against records, keeps the run reports and exposes the active
skills in a Solr catalogue.
