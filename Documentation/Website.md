# TYPO3 Lab website information

Canonical website: [typo3-lab.webconsulting.at](https://typo3-lab.webconsulting.at).

**Title:** Skillflow — AI-assisted TYPO3 review workflows

**Description:** Assign nr_llm-managed skills to TYPO3 pages, backend users
and workspace review stages. Review draft content with a configured AI engine
and keep status and reports in TYPO3. The Solr catalogue exposes active skills
with metadata, facets and detail pages.

**Requirements:** TYPO3 14.3.6+, PHP 8.4+, nr_llm 0.34.x, EXT:solr 14.0.1+.

**Scope:** nr_llm manages sources, imports and activation. Skillflow manages
assignments, execution and run history. Execution defaults to local DDEV;
reports are advisory. Supporting scripts are not materialized, and license/
SkillSpector scanning is not bundled.
